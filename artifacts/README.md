# Workspace Artifacts

This directory stores all persistent deliverables, discovery models, architecture diagrams, and specification files generated by custom agents and skills.

---

## Directory Structure

```text
artifacts/
├── opportunity-solution-trees/   # Opportunity Solution Trees (OST markdown & FigJam/Miro CSVs)
├── story-maps/                   # Two-Dimensional Story Maps & Release Slice tables
├── user-stories/                 # Sprint-ready user story specifications & acceptance criteria
├── journey-maps/                 # User journey maps, empathy maps & task flow diagrams
├── design-systems/               # Design tokens, color palettes, typography & component specs
├── wireframes-and-flows/         # Screen layouts, interaction specs & wireframe blueprints
├── visual-designs/               # Final High-Fidelity visual mockups, HTML/CSS prototypes & visual specs
└── architecture/                 # System architecture blueprints, topology models, ER diagrams & API contracts
```

---

## Naming Conventions

All agents and skills save their deliverables into their designated subfolder using kebab-case naming:

- **Opportunity Solution Trees**: `artifacts/opportunity-solution-trees/<initiative-name>-ost.md`
- **Story Maps**: `artifacts/story-maps/<initiative-name>-story-map.md`
- **User Story Specifications**: `artifacts/user-stories/<initiative-name>-user-stories.md`
- **User Journey Maps**: `artifacts/journey-maps/<initiative-name>-journey-map.md`
- **Design Systems**: `artifacts/design-systems/<initiative-name>-design-system.md`
- **Wireframes & Screen Specs**: `artifacts/wireframes-and-flows/<initiative-name>-wireframes.md`
- **High-Fidelity Visual Designs**:
  - Image Render: `artifacts/visual-designs/<initiative-name>-mockup.png`
  - Interactive Prototype: `artifacts/visual-designs/<initiative-name>-mockup.html`
  - Visual Spec Sheet: `artifacts/visual-designs/<initiative-name>-visual-spec.md`
- **System Architecture**: `artifacts/architecture/<initiative-name>-architecture.md`

*(For comprehensive product initiatives spanning multiple stages, agents may also create an initiative-scoped folder: `artifacts/<initiative-name>/`)*
